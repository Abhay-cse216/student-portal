# EduTrack — AI-Assisted Student Portal
## End Semester Examination Project

### 1. Introduction
EduTrack is a simple web application prototype for the Education domain. It provides students with one place to view academic information such as courses, attendance, assignments, timetable, notices and profile details.

### 2. Problem Statement
Students often use different sources to check class schedules, assignments, attendance and university notices. A centralized student portal can organize these academic activities in one easy-to-use interface.

### 3. Objective
To develop a simple, responsive and interactive student portal prototype using AI-assisted planning, code generation, testing and improvement.

### 4. Target Users
- Students
- Faculty/academic staff (future extension)
- University administration (future extension)

### 5. Functional Requirements
- View academic dashboard
- View courses and attendance
- Filter courses
- View and submit assignments
- Add a personal assignment
- View weekly timetable
- Search notices
- View/edit profile name
- Toggle dark mode
- Responsive navigation

### 6. Technologies
- HTML5
- CSS3
- JavaScript
- Google Fonts
- AI-assisted prompt engineering

### 7. AI Usage
AI was used for:
- Problem definition
- Requirement planning
- UI/UX planning
- Code generation
- JavaScript interaction design
- Debugging
- Responsive improvements
- Test-case generation
- Final review

### 8. System Flow
Student → Login/Portal Entry → Dashboard → Select Module → View/Update Academic Information → Receive Feedback

### 9. Limitations
This is a front-end prototype. It uses sample data and browser-side interactions. It does not include a real university database, authentication server or backend API.

### 10. Future Scope
- Secure student login
- Real database integration
- Faculty dashboard
- Online assignment file upload
- Real attendance synchronization
- Examination results
- Push/email notifications
- AI study assistant

### 11. Conclusion
The EduTrack prototype demonstrates how prompt engineering and AI tools can support the complete software-development process from problem identification and planning to code generation, testing and improvement.
