# EduTrack Student Portal — ESE Prototype

## Run
1. Open the `student-portal` folder.
2. Double-click `index.html`, or open it with a browser.
3. No server or installation is required.

## Demo Flow
Dashboard → Courses → Attendance → Assignments → Add Assignment → Submit → Timetable → Notices → Profile → Dark Mode.

## Files
- index.html — application structure
- style.css — responsive UI styling
- script.js — interactions
- PROMPT_BOOK.md — prompt engineering record
- TESTING_TABLE.md — test cases and results
- PROJECT_REPORT.md — ESE project report

## Note
This is an academic front-end prototype using sample data. Do not use real student personal information in a public deployment.
